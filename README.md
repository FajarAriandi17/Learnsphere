# EduSoal AI

> **AI-Powered Teacher Productivity Platform for Indonesian Education**

EduSoal AI is a modern SaaS web application that helps teachers create school assessments and automate academic administration in minutes. Built specifically for the Indonesian education system with curriculum-aware AI generation and professional document exports.

## ✨ Features

* 🤖 AI Exam & Question Generator
* ✅ Answer Key & Explanation Generator
* 📚 Kurikulum Merdeka & Kurikulum 2013 Support
* 📝 Report Card (Raport) Generator
* 📅 Student Attendance Management
* 🗂️ Student Portfolio Generator
* 📄 Export to DOCX, PDF & Excel
* 👨‍🏫 Student, Class & School Management
* 📊 Teacher Dashboard & Document History

## 🛠 Tech Stack

| Layer      | Technology               |
| ---------- | ------------------------ |
| Frontend   | Next.js 15 + TypeScript  |
| UI         | Tailwind CSS + shadcn/ui |
| Database   | Supabase PostgreSQL      |
| Auth       | Supabase Auth            |
| Storage    | Supabase Storage         |
| Backend    | Insforge                 |
| Deployment | Cloudflare               |

## 🎯 Product Vision

> *Helping Indonesian teachers complete assessment creation and academic administration in minutes, not hours.*

EduSoal AI focuses on simplicity, affordability, and real classroom productivity rather than being a generic AI chatbot.
